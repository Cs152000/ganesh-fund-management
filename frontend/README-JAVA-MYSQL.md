# Ganesh Fund - React connected to Java + MySQL

1. Start MySQL and create `ganesh_fund`.
2. Start the Spring Boot backend on port 8080.
3. Copy `.env.example` to `.env.local`.
4. Run `npm install` and `npm run dev`.
5. React calls `http://localhost:8080/api`; the backend reads/writes MySQL.
6. Login with the configured admin credentials.
